# انتاجيتي 🚀 | مركز الإنتاجية الذكي الشامل

<div dir="rtl">

تطبيق سطح مكتب احترافي غني لنظام **Windows** يُعالج الكسل ويساعدك على التركيز والالتزام في الدراسة، العمل، والدين عبر واجهة زجاجية عصرية وحظر ذكي للتطبيقات والمواقع مع تذكيرات صحية وإيمانية دورية.

---

## ✨ المميزات الرئيسية الشاملة

### 🚫 حظر التطبيقات والمواقع الذكي
- **حظر تلقائي وتلقائي ومباشر**: إغلاق جميع التطبيقات والمواقع الممنوعة أثناء وقت التعلم.
- **وضع التعلم الصارم الإجباري (Strict Mode)**: لمنع إيقاف التعلم أو فك الحظر يدوياً حتى انقضاء الوقت المحدد.
- **إنهاء تلقائي**: تنتهي جلسة التعلم فور وصول وقت النهاية المحدد وتلغى القيود تلقائياً.

### 👀 راحة العينين والبدن (قاعدة 20-20-20)
- **شاشة كاملة غامرة**: تظهر كل 20 دقيقة لتوجيهك للنظر إلى نقطة بعيدة واسترخاء العينين.
- **قفل الزر لمدة 20 ثانية**: لا يمكنك إغلاق شاشة راحة العين حتى تنتهي الـ 20 ثانية بالكامل لضمان راحة عينيك.

### ⏳ مؤقتات التذكير الحية على الواجهة الرئيسية (Dashboard)
- بطاقة حية تُظهر الوقت المتبقي لـ: **راحة العينين** 👀، **التمرين الرياضي** 🏋️، و**شرب الماء** 💧.
- **إخفاء ذكي**: إذا تم تعطيل أحد التذكيرات، يختفي المربع الخاص به تلقائياً. وإذا عُطلت جميعها، تختفي البطاقة بالكامل.

### 🚀 أزرار العمل السريع المخصصة (Quick Launch Profiles)
- إضافة عدة بيئات تشغيل سريعة (مثل: بيئة البرمجة 💻، بيئة الدراسة 📖، بيئة العمل 💼).
- فتح جميع البرامج والمواقع المرتبطة بالبيئة بنقرة زر واحدة.
- إدارة كاملة (إضافة، تعديل، تسمية، وحذف البيئات الأزرار).

### 📿 مواعيد الصلاة والسنن والأذكار النوافل
- **مواعيد الصوات الخمس**: تنبيه بصوت أذان غامر، مع إغلاق كافة الألعاب والممنوعات لمدة 5 دقائق إجبارياً للصلاة.
- **تنبيهات السنن والأذكار**: تخصيص كامل للسنن والنوافل (صلاة الضحى ☀️، أذكار الصباح 🌅، أذكار المساء <ctrl42>، قيام الليل 🌙، سنة الفجر 🌅) مع إمكانية تحديد الوقت لكل سنة بشكل فردي.

### 📅 تذكير المواعيد والتذكيرات المفردة
- إمكانية إضافة تذكير بموعد عند وقت محدد.
- تمييز بصري: لون **أصفر** للمواعيد العادية، ولون **أحمر صارم** للمواعيد الإجبارية.

### 📁 مجلد الإنجازات والشهادات (Portfolio System)
- إمكانية إنشاء مجلدات وتسميتها ورفع صور الشهادات والإنجازات بها.
- عرض الصور داخل المجلد، وإمكانية إضافة مجلدات فرعية، واستعراض الشهادات بمكبر الصور وعرض ملء الشاشة.

## 📥 طريقة التثبيت والتشغيل

### 🟢 الطريقة السهلة (تشغيل مباشر):

1. شغّل **`SETUP_RUN.bat`** بنقرة واحدة — وسيتم تشغيل الـ EXE المباشر أو تثبيت المكتبات وتنسيق كل شيء تلقائياً!
2. أو افتح مجلد `dist/` وشغّل **`انتاجيتي.exe`** مباشرة.

---

### 🔧 التشغيل من السورس كود (Python):

#### المتطلبات:
- Python 3.11+ / 3.12+
- Windows 10 / 11

#### خطوات التشغيل:

```bash
# 1. استنسخ المشروع
git clone https://github.com/wkrohz/-.git
cd -

# 2. ثبّت المكتبات
pip install -r requirements.txt

# 3. شغّل التطبيق
python main.py
```

---

### 🏗️ إعادة بناء الـ EXE بنفسك:

```bash
pip install pyinstaller
pyinstaller --noconfirm ProductivityHub.spec
```

سيظهر الـ EXE في مجلد `dist/انتاجيتي.exe`.
