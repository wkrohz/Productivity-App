# 🚀 مركز الإنتاجية الذكي | Productivity & Focus Hub

تطبيق سطح مكتب احترافي مخصص لنظام الويندوز لزيادة الإنتاجية والتركيز، يتضمن نظام حظر تطبيقات التعلم الذكي وتنبيهات صحية دورية ملء الشاشة لشرب الماء وتمارين الضغط.

---

## ✨ المميزات الرئيسية
- **🚫 حظر التطبيقات الممنوعة**: حظر وإغلاق التطبيقات المحددة تلقائياً أثناء وقت التعلم.
- **⚡ أزرار الجلسات السريعة**: بدء جلسة تعلم بنقرة واحدة (30 دقيقة / 45 دقيقة / ساعة / ساعتان).
- **📅 جداول التعلم**: تحديد مواعيد تعلم تلقائية بنظام 12 ساعة (صباحاً/مساءً).
- **💧 تنبيه شرب الماء**: شاشة كاملة دورية كل 40 دقيقة مع صوت منبه متكرر.
- **🏋️ تنبيه تمارين الضغط (Push-ups)**: شاشة كاملة كل ساعتين لتحدي 5 ضغطات وتجديد النشاط.
- **⚙️ الإقلاع الذاتي (Windows Startup)**: تشغيل تلقائي عند إقلاع الجهاز مع العمل في صينية النظام (System Tray).

---

## 📥 طريقة التشغيل والتحميل

### 1️⃣ التشغيل المباشر (EXE):
- قم بفتح المجلد وافتح `dist/ProductivityHub.exe` مباشرة بدون الحاجة لتثبيت بايثون.

### 2️⃣ التشغيل من السورس كود (Python Source Code):
1. قم بتثبيت متطلبات بايثون:
   ```bash
   pip install -r requirements.txt
   ```
2. شغل التطبيق:
   ```bash
   python main.py
   ```
   أو اضغط مرتين على `SETUP_RUN.bat`.

---

## 🛠️ التقنيات المستخدمة
- **Python 3.11**
- **PySide6 (Qt for Python)** - واجهة مستخدم فائقة الجمال والتجاوب
- **Psutil** - فحص وحظر العمليات الحية
- **Winreg** - التشغيل التلقائي مع الويندوز
