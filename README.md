# انتاجيتي 🚀 | مركز الإنتاجية الذكي

<div dir="rtl">

تطبيق سطح مكتب احترافي لنظام **Windows** يساعدك على التركيز والإنتاجية عبر حظر تطبيقات التشتت وتنبيهات صحية دورية ذكية.

---

## ✨ المميزات الرئيسية

- **🚫 حظر التطبيقات**: إغلاق التطبيقات الممنوعة تلقائياً أثناء وقت التعلم
- **⚡ جلسات سريعة**: ابدأ جلسة تعلم بنقرة واحدة (30 / 45 / 60 / 120 دقيقة)
- **📅 جدول مواعيد**: حدّد مواعيد تعلم يومية بنظام صباحاً/مساءً
- **💧 تنبيه شرب الماء**: شاشة كاملة كل 40 دقيقة مع صوت منبّه
- **🏋️ تنبيه تمارين الضغط**: شاشة كاملة كل ساعتين لتجديد نشاطك
- **🔍 بحث الويندوز**: يسجّل نفسه تلقائياً في قائمة Start Menu
- **⚙️ إقلاع تلقائي**: يعمل مع تشغيل الجهاز في System Tray

---

## 📥 طريقة التثبيت والتشغيل

### 🟢 الطريقة السهلة (EXE جاهز):

1. افتح مجلد `dist/`
2. شغّل **`انتاجيتي.exe`** مباشرة — بدون الحاجة لأي شيء آخر!
3. عند أول تشغيل، يُضيف التطبيق نفسه لبحث الويندوز تلقائياً
4. ابحث عن `انتاجيتي` في بحث الويندوز (Win + S) وسيظهر فوراً

> **ملاحظة:** الـ EXE لا يُرفع على GitHub بسبب حجمه الكبير. حمّله من [Releases](../../releases) أو شغّله من السورس كود.

---

### 🔧 التشغيل من السورس كود (Python):

#### المتطلبات:
- Python 3.11+
- Windows 10/11

#### خطوات التثبيت:

```bash
# 1. حمّل المشروع
git clone https://github.com/wkrohz/-.git
cd -

# 2. ثبّت المكتبات
pip install -r requirements.txt

# 3. شغّل التطبيق
python main.py
```

أو اضغط مرتين على **`SETUP_RUN.bat`** لتثبيت كل شيء وتشغيله تلقائياً.

---

### 🏗️ بناء الـ EXE بنفسك:

```bash
pip install pyinstaller
pyinstaller --clean ProductivityHub.spec
```

سيظهر الـ EXE في مجلد `dist/انتاجيتي.exe`
